# WebTyper

WebTyper 是一款結合網頁介面與 nRF52840 開發板的無線文字輸入工具，讓使用者在手機或其他支援 Web Bluetooth 的裝置上準備文字，再透過開發板將文字輸入到電腦目前游標所在的位置。

## 運作方式

WebTyper 透過藍牙低功耗（Bluetooth Low Energy，BLE）將網頁中的文字傳送至 nRF52840 開發板。開發板以 USB HID 鍵盤的形式連接電腦，將收到的文字轉換為鍵盤按鍵輸入，因此目標電腦不需要執行專用的接收程式。

**網頁介面 → BLE → nRF52840 → USB HID 鍵盤 → 電腦**

## 主要特色

- **網頁操作介面**：在瀏覽器中輸入或貼上文字，完成裝置連線與傳送操作。
- **無線文字傳輸**：透過 BLE 連接開發板，方便從另一台裝置準備與傳送內容。
- **USB 鍵盤輸入**：由開發板模擬鍵盤，將文字輸入至目標電腦的文字欄位或編輯器。
- **可調整的傳送設定**：提供輸入速度及輸入法切換快捷鍵設定，並可停止輸入。
- **適合手機的深色介面**：首頁集中呈現裝置連線與文字輸入區，其他設定收納於選單中。

## 適用範圍

WebTyper 適合輸入英文文字、數字、ASCII 符號，以及由這些字元組成的程式碼或指令。目前版本不支援中文與 Emoji，實際輸入結果也會受到目標電腦的鍵盤配置、輸入法及應用程式行為影響。

網頁端需使用支援 Web Bluetooth 的瀏覽器，並透過 HTTPS 或 localhost 開啟；硬體端使用搭配相應韌體的 nRF52840 開發板。
